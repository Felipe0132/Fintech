# Fintech - Gestão Financeira Pessoal 💰

Projeto de controle e gestão financeira pessoal desenvolvido em **Python** utilizando o framework **Django**.

## 📌 Sobre o Projeto

O **Fintech** nasceu da necessidade prática de gerenciar dados e finanças pessoais de maneira eficiente, personalizada e totalmente gratuita. 

Incomodado por não encontrar uma solução ideal sem ter que recorrer a aplicativos pagos por assinatura, decidi unir o útil ao agradável: colocar a **mão na massa para aprender Python e Django** resolvendo um problema real da minha rotina diária.

### 🎯 Objetivos do Projeto
- **Aprendizado Prático**: Dominar a sintaxe do Python e a arquitetura MVT (Model-View-Template) do Django.
- **Modelagem e Gestão de Dados**: Estruturar banco de dados relacionais para representar receitas, despesas e relatórios financeiros.
- **Autonomia Financeira**: Ter uma ferramenta própria de controle de orçamento sem custos de mensalidades.

---

## 🚀 Funcionalidades do Sistema
- 👤 **Autenticação de Usuários**: Cadastro, login, logout e controle de acesso individual aos dados.
- 💵 **Gestão de Transações**: Registro de receitas (entradas) e despesas (saídas).
- 🏷️ **Categorização de Gastos**: Organização por categorias (ex.: Alimentação, Moradia, Lazer, Transporte, Investimentos).
- 📊 **Dashboard Financeiro**: Resumo visual de saldo total, entradas vs. saídas do mês.
- 📅 **Filtros e Histórico**: Consulta de lançamentos por datas, tipos de transação e categorias.

---

## 🛠️ Tecnologias Utilizadas
- **Linguagem**: Python 3.x
- **Framework Web**: Django
- **Banco de Dados**: SQLite (padrão de desenvolvimento) / PostgreSQL (produção)
- **Frontend**: HTML5, CSS3, JavaScript (Bootstrap / Tailwind CSS)
